# 📊 Sales Data Analytics & Exploratory Data Analysis Project

## 📌 Project Overview

This project focuses on analyzing sales data using Exploratory Data Analysis (EDA) techniques and Pivot Table reporting. The goal is to extract meaningful insights from raw data and support data-driven decision-making.

## 🎯 Objectives

* Clean and organize the dataset
* Perform Exploratory Data Analysis (EDA)
* Analyze sales orders and transactions
* Evaluate product performance
* Study payment method trends
* Generate business insights through Pivot Tables
* Create a comprehensive project summary report

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Data Analysis Techniques
* Data Visualization
